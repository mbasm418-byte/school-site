# تحويل الموقع إلى تطبيق (PWA)

## ما تم

أضفنا إلى الموقع ملفات تجعله قابلًا للتثبيت كتطبيق على الهاتف، ويعمل بدون إنترنت للصفحة الأساسية:

- `manifest.json` — اسم التطبيق وأيقوناته وألوانه.
- `sw.js` — Service Worker يخزّن الصفحة والأيقونات والخطوط للعمل دون اتصال.
- أيقونات التطبيق: `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`.
- تعديل `index.html`: ربط الـ manifest، وسوم iOS، وزر «تثبيت التطبيق» يظهر تلقائيًا على أندرويد.

ملفات PDF لا تُخزَّن مؤقتًا (حجمها كبير) وتُفتح من الشبكة عند الطلب.

## خطوات النشر

1. افتح مستودع `school-site` على GitHub.
2. ارفع الملفات التالية إلى جذر المستودع (بجانب `index.html`):
   - `index.html` (النسخة المعدّلة — استبدل القديمة)
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-512-maskable.png`
   - `apple-touch-icon.png`
3. انتظر دقيقة أو دقيقتين حتى ينشر GitHub Pages التحديث.
4. افتح `https://mbasm418-byte.github.io/school-site/` من الهاتف.

## التثبيت على الهاتف

- أندرويد (Chrome): يظهر زر «تثبيت التطبيق على جهازك» أسفل الصفحة، أو من قائمة المتصفح ← «تثبيت التطبيق».
- آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يفتح الموقع بشاشة كاملة بدون شريط المتصفح، ويظهر بأيقونة خاصة.

## ملاحظة عند تحديث الموقع لاحقًا

إذا عدّلت `index.html` أو الأيقونات، غيّر رقم النسخة في أول سطر من `sw.js`:

```js
const VERSION = 'v2';
```

بهذا يحذف الهاتف النسخة القديمة من الذاكرة المؤقتة ويجلب الجديدة.

## إذا أردت تطبيقًا في المتاجر (APK / App Store)

PWA يكفي للتثبيت المباشر. أما النشر في Google Play فيحتاج تغليفًا إضافيًا (APK/AAB) عبر PWABuilder أو Capacitor — الخطوة التالية إن أردت.
